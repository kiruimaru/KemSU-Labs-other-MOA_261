# KemSU-Labs-other-MOA_261

Здесь собраны и будут собираться все мои работы в КемГУ

## Как скачать репозиторий?

```bash
git clone git@github.com:kiruimaru/KemSU-Labs-other-MOA_261.git
```
### Структура репозитория
```
KemSU-Labs-other-MOA_261/
├── README.md              # Описание проекта
└── 1-semester/            # Первый семестр
    ├── CS/                # Информатика (Computer Science)
    ├── IPA/               # Введение в профессиональную деятельность(introduction in professional activity)
    ├── YAP/               # Языки программирования
    ├── AVS/               # Архитектура вычислительных систем
    └── Notes/             # Конспекты, лекции и база знаний
```
### Используемое программное обеспечение
```
- OS: Omarchy Linux
- IDE: Visual Studio, Zed
- Notes: Obsidian
- DOCX: Google Docs, WordCraft, LibreOffice
- AI Agents: Claude Code (чаще Sonnet, реже Opus)
```
